# Birdy Place

Static Spanish and Ukrainian website for Birdy Beauty Workshop in Torrevieja.

## Local preview

```sh
npm ci
npm run dev
```

## Build

```sh
npm ci
npm run check
npm run build
```

GitHub Actions publishes `dist/` to GitHub Pages on pushes to `main`.

The generated salon images are illustrative and do not depict Birdy staff, clients, premises or actual work.
